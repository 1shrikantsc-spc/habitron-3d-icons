# 🎨 Habitron 3D Habit Icons CDN

High-resolution 3D habit icon library for the **Habitron** mobile app.
Delivered globally via [jsDelivr](https://www.jsdelivr.com/) Multi-CDN edge network.

## 📁 Category Structure
- `fitness/` - Fitness & Workout 3D Icons
- `health/` - Nutrition & Health 3D Icons
- `mindfulness/` - Meditation & Peace 3D Icons
- `productivity/` - Goals & Focus 3D Icons
- `learning/` - Education & Skill 3D Icons
- `finance/` - Money & Investment 3D Icons
- `general/` - Badges & Rewards 3D Icons

## ⚡ CDN URL Format
```
https://cdn.jsdelivr.net/gh/1shrikantsc-spc/habitron-3d-icons@main/<category>/<filename>.png
```
